## Before you insert — three things

**1. Word's image compression — only affects Figure 1 now.**
Word downsamples raster images to 220 ppi on insert by default. That is almost certainly
why the document has soft images despite 600 dpi sources. Using SVG for Figures 2–23
sidesteps it completely: vector is not rasterised or downsampled, so the setting cannot
silently undo the fix. Figure 1 is the only raster file in this folder.

Where the setting lives depends on platform:

- **Word for Mac** — *not* File → Options; that menu is Windows-only. Try **Word menu
  (top-left, beside the Apple logo) → Preferences (⌘,) → Save**. Several Word for Mac
  builds do not expose a global "do not compress" checkbox at all, in which case use the
  per-picture route: click the image → **Picture Format** tab → **Compress Pictures…** →
  highest quality, applied to **All pictures in this file**.
- **Word for Windows** — File → Options → Advanced → Image Size and Quality → tick **"Do
  not compress images in file"**, default resolution **High fidelity**.

Simplest check either way: insert Figure 1, export to PDF, and zoom to 400% on the axial
slices. If they are sharp, compression is not biting.

**1a. Check text rendering after the first SVG insert.** These are matplotlib SVGs that
reference fonts by name rather than embedding them. Word 2016 / 365 renders SVG natively,
but if a referenced font is missing it substitutes, which can shift axis labels or overlap
tick text. Insert Figure 2 first, look at it, and if the text is wrong use the PNGs
throughout instead — they are 600 dpi and perfectly acceptable for IEEE.

**2. Figure 5 will need regenerating.** It currently shows two comparators. Once the
MAE/DINO/contrastive SSL results go in (see `WORD_AGENT_PROMPT_R2.3_SSL.md`), panel A
needs all five pretraining objectives. Inserting the current version now is throwaway
work — either do Figure 5 last, or accept it will be replaced.

**3. Six of these are currently `[FIGURE PLACEHOLDER` text markers** in the document, not
low-resolution images: Figures 2, 5, 8, 14, 18, 19. Those need the marker deleted and the
image inserted; the other 17 are replace-in-place.

## 1. R1.3 flipped from NO to YES — external validation was run

`experiments/zenodo_external_validation/` (commit e389ba6) derives FastSurfer nWBV for
the van den Broek cohort with the same `--seg_only` pipeline and BrainSeg/Mask
definition used for OASIS-1 and ds006557. The labels are comparable; the earlier
`zenodo_validation/` intensity-proxy run is superseded and marked do-not-cite.

Outcome, reported as measured: adapted MAE **0.0731** (r 0.255, p 0.477), unadapted
**0.0327**, cohort constant-mean baseline **0.0089**. Label ranges do not overlap
([0.752, 0.808] vs [0.836, 0.869]); predictions collapse to 0.7824 against an
adaptation mean of 0.7841. The model returns its training mean and does not
extrapolate — the internal §V-E finding (r = −0.119) reproduced at an independent site.

Touched: `01` (I8), `02` (new rows + do-not-cite), `03` (R1.3 → YES; tally 20/2/2),
`05` (M19, M20 revised; **M30** new), `06` (R1.3 block rewritten; preamble),

## 2. I10 — the 47 ms GPU latency claim is withdrawn

No measurement file exists anywhere in the repository. "47 ms" appears only as a
hardcoded literal in four figure scripts, and the same `0.047` is assigned to two
different models in fig10's latency array. `CLAUDE.md` records the development GPU as
CUDA-incompatible, so a GPU benchmark could not have been produced on that hardware.

Withdrawn and replaced by a measured CPU benchmark under a stated protocol (**M29**).
CPU-only operation is the stronger point-of-care claim in any case. Do not substitute
an estimate: if the benchmark cannot be produced, delete the claim.

Touched: `01` (I10), `05` (M1 revised, **M29** new), `06` (preamble), `07` (fig10 now
requires rebuild), `08` (Risk 4, grep gate).

## 4. Subject-count discipline (M31)

The external cohort has **11 paired** subjects; **10** were analysable (`sub-0064`
incomplete). `zenodo_validation_results.json` is internally inconsistent on this —
`paired_subjects` lists 11 while `num_subjects` is 10. Every mention must distinguish
the two. The number appears inside a disclosed correction, where a wrong value costs
more than anywhere else.
